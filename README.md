# 山院 · 3D 实景重建

依据同目录上级的 `1.jpeg`—`4.jpeg` 制作的 Three.js 实时庭院场景。建筑、家具、竹篱、院门与植被全部由几何体构成，石材、青砖、瓦面、木纹、藤编与布料的贴图在浏览器里程序化生成，不依赖外部模型或贴图。

## 打开

- macOS：双击 **`打开 3D 庭院.command`**。
- 或在当前目录运行：

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173`。

## 交互

- 拖拽旋转、滚轮缩放、右键平移；触屏支持单指旋转与双指缩放。
- 底部切换庭院全景、建筑立面、户外茶歇、竹篱木门四个机位。
- 右侧拖动时间，或选择午后、黄昏、夜晚。
- 右下角依次开启物件标注、自动环绕、重置视角。
- 顶部查看四张原图，或保存当前视角为 PNG。
- 快捷键 `1`—`4` 切换机位，`R` 重置，`L` 切换标注。

## 光与材质

- **光**：14:30 的斜阳从左前方进入院子，4K 阴影贴图投下屋檐、竹篱与树叶的影子；角色坐标与天空着色器共用同一套太阳方位。17:30 以后转为低角度金色光，19:30 进入蓝调时刻，檐下灯笼与室内暖光逐渐亮起。
- **天空**：自写的大气渐变着色器，含地平线薄雾、太阳光晕和夜空星点；同一片天空会被烘焙成 PMREM 环境探针，让玻璃、铝梯、石面反射出真实的院子天色。
- **材质**：每种材质都有 albedo、法线、粗糙度三张程序化贴图，并按真实尺寸缩放 UV——砖基约 9 cm 一皮、瓦面约 25 cm 一条、木平台与藤编都有独立纹理；另外叠加了接触阴影、落叶、草叶实例与远处山林的空气透视。

- 深色门窗、窗棂、纱帘、双开玻璃门、吊灯、监控、雨水管、铝梯和晾衣杆。
- 木平台、四把藤编椅、条板茶几、茶具、两把帆布折叠椅、烧烤炉、黑色高桌。
- 洗衣机及紫色盖布、纸箱、红色收纳箱、木凳、木柴、编织袋、小狗、空调外机。
- 竹篱、木门门闩与铰链、分层茅草顶、石板小径、草坪、竹林、乔木、红枫、造型松、灌木和景石。
- 白兔摆件、太阳能灯、远山、远处的邻居屋顶和横过天空的电线。

## 精度说明

这是**照片引导的程序化三维重建**，不是摄影测量、激光扫描或施工级模型。照片未显示的背面、遮挡部分和绝对尺寸作了合理推定；材质用于还原视觉特征，并非实物采样。四张原图保留在 `public/references/`，可在页面中直接对照。

## 构建与检查

```bash
npm run build
# 先启动开发服务器，再运行：
npm run test:visual
```

视觉检查覆盖四个机位、午后/夜晚、物件标注、原图切换及手机尺寸，截图输出到 `screenshots/`。脚本可通过 `CHROMIUM_PATH` 指定本机 Chromium；默认路径是当前机器已安装的 Playwright Chromium。

静态零件按材质合批，瓦片、竹枝、草叶、树叶和落叶使用实例化渲染；静止时停止重复绘制，以降低显卡占用。
